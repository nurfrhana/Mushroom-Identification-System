[Outline]

[Concepts]
- The key concept of Machine Learning is the self-learning capability which is achieved through statistical models and data. Self-learning involves using statistical modeling to discern patterns and enhance performance based on data and empirical knowledge, all without the need for explicit programming commands.

[Frameworks/Model/Method/Algorithm/Tool]
- Decision Tree: Worked in a hierarchical tree structure with the utmost node called ‘root node’ as the main point of the tree that represents the datasets.
- K-Nearest Neighbors (KNN): Also called “lazy learning”, an instance-based learning methodology. It works by postponing the training datasets to be processed completely until it encounters a test query for prediction.
- Support Vector Machines (SVM): Algorithm which finds the maximized hyperplane that acts as the margin between two classes of data to explain the relationship between dependent and independent variables.

[Fit to problem]
- Machine Learning learn from a large datasets and give a prediction or outcome based on given input would help in the mushroom identification system. A datasets containing labeled edible and non-edible mushrooms will be used to train the model to recognise them and implied in the pending application.
- Benefits: 
i) Easily identifies trends and patterns by reviewing large scales of data
ii) Continuous improvement in efficiency and accuracy as it gains experience.
- Limitations:
i) Data acquisition, since Machine Learning effectiveness depends on quality and size of the datasets it requires a massive, unbiased and good quality of datasets to train on.
ii) Time consuming as it needs enough time to learn and develop in order to fulfill the purpose with great accuracy.

[Comparison]
- Machine Learning is chosen besides Deep Learning because it is an image recognition technique that is suitable in recognising the images of mushroom dataset and it can learn from the datasets and provide an accurate outcome in identifying the types of mushroom based on users' uploaded photos.
