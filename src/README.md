# [A Mobile-Based Mushroom Identification System for Foragers Using Machine Learning.]

This project aims to help prevent local foragers and rural residents from misidentifying mushrooms edibility.

## Problem statement
Foragers and rural people need a mushroom identification system that gives user instant confirmation of a mushroom edibility. This is because rural residents mostly had been relying on passed down information and trial-and-error method. This issue can caused people to high possibility of mushroom poisoning case as the method used to identify mushroom edibilty is unrliable and risky.
